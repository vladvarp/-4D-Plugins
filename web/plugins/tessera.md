## О плагине
[[mdb:'Интерфейс'-n'ID1'-b8]]
Tessera — генератор облицовки для Cinema 4D. Это не только пол: тот же объект кладёт доски и плитку на **пол, стену и потолок**. Дочерний контур не обязателен — у объекта свой размер. Если нужен произвольный силуэт с окнами, включи **Контур из дочернего объекта**.

Каждая плитка — отдельный 3D-элемент с толщиной, фаской и швом. Под плиткой можно поднять **подложку**: зазор шва показывает слой снизу, как у реального покрытия. Раскладка **Plank** даёт доски разной длины; **Keep Intact** отбрасывает обрезанные фрагменты вместо кромсания плиток по границе.

:::info
Плагин — генератор объектов. Появляется в меню Create / Extensions после регистрации `PLUGIN_ID` с Plugin Café.
:::

## Возможности

::::features
### 📐 Пол, стена, потолок
Один объект, три ориентации. Без дочерней плоскости — задай размер A×B. С дочерним полигоном — обрезка по контуру и отверстиям.

### 🧱 Тринадцать раскладок
`Plank` доски с рандомной длиной.
`Running / Stack / 1/3 / English Bond` кладки.
`Herringbone 90` и настоящий `Chevron`.
`Basket`, `Windmill`, `Versailles`, `Hex`, `Diamond`, `Fish Scale`.

### 🪵 Подложка и шов
Толщина плитки, фаска, ширина шва и отдельный слой подложки. Шов — реальный зазор, а не только inset «в никуда».

### ✂️ Keep Intact
Не резать плитки по контуру: фрагменты, которые не влезают целиком, отбрасываются.

### 🎲 Jitter
Разброс высоты и угла каждой плитки — неидеальная укладка.

### 🏷️ Материалы
Теги `TILE`, `SIDE`, `CUT`, `BORDER` и `MAT_1`…`MAT_n` для нескольких текстур дерева/камня.
::::

## Использование

### Без контура
1. Создай объект `Tessera`
2. Выбери тип поверхности: пол, стена или потолок
3. Задай размер A и B
4. Выбери раскладку и размеры плитки

### С контуром
1. Создай плоский полигон нужной формы (можно с отверстиями)
2. Сделай его дочерним к `Tessera`
3. Включи **Контур из дочернего объекта**

:::tip
Для паркета включи Plank, разброс длины 30–50% и 3 группы `MAT_n` — доски не будут клонами одной текстуры.
:::

### Теги выделения

| Тег | Назначение |
|-----|------------|
| **TILE** | Верх плиток |
| **SIDE** | Бока и фаска |
| **CUT** | Плитки, обрезанные контуром |
| **BORDER** | Рамка по периметру |
| **MAT_n** | Группа материала |

## Ограничения

- Контур должен быть **плоским**
- Слишком большая площадь — тысячи плиток, генерация замедляется
- Нужен уникальный `PLUGIN_ID` с Plugin Café, иначе объект в C4D не регистрируется

:::warning
Перед тестом на огромной плоскости сохрани сцену. Лимит генерации — 14000 плиток.
:::
